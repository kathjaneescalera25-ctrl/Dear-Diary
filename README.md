# Dear Diary

A simple personal diary website where users can write, save, and revisit their thoughts and memories.

## Features
- Create diary entries with title, date, mood, and content
- Edit or delete previous entries
- Search entries by keyword
- View total count and monthly stats
- Stores entries in the browser using `localStorage`

## Run locally
Open `index.html` in a browser.

You can also use a simple local server if you prefer:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files
- `index.html` — app layout
- `style.css` — styling and responsive design
- `app.js` — diary logic and storage
